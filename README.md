This is a simple To-Do software made by Go.<br>
Usages:<br>
todo add [Title] [Description]<br>
todo list<br>
todo list all <br>
todo done [Title] <br>
todo erase [Title] <br>
This software's display language is currently Japanese only.<br>
Multiple tasks with the same name cannot exist at the same time.<br>
todo erase will erase all tasks with the specified name from the file.<br>
Currently, I only make binaries for Linux amd64.<br>
これはGoで作ったシンプルなTo-Doソフトです。<br>
使い方:<br>
todo add [タイトル] [説明]<br>
todo list <br>
todo list all <br>
todo done [タイトル]<br>
todo erase [タイトル]<br>
このソフトの表示言語は現時点で日本語のみです。<br>
同名の未完了のタスクは複数同時に存在できません。<br>
todo eraseはファイルから指定されたタイトルのタスクを全て削除します。<br>
現時点ではLinux amd64用のバイナリのみがあります。
